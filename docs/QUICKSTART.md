# 快速开始

[返回首页](../README.md)

## 1. 安装

从 [Releases](https://github.com/luiop4/code-swarm/releases/latest) 下载最新 VSIX。VS Code 扩展面板 **… → 从 VSIX 安装…**，安装后按提示重新加载窗口。本项目尚未发布到 Marketplace。

## 2. 先看演示

按 `Ctrl+Shift+P` 运行 **Code Swarm: 播放完整演示**。舞台会依次播放生成、移动和修改场景，可以暂停、调速、拖动进度、重播。演示使用内置代码，不改真实文件。

## 3. 选择输入来源

打开本地代码文件，运行 **Code Swarm: 选择代码输入来源**。

| 入口 | 使用方法 |
|---|---|
| VS Code AI | 描述任务、选择可用模型；响应片段持续流入动画输入控制器 |
| Copilot Agent | 启用工具并使用 `#swarm_animate_edit`；详见首页步骤 |
| 普通文件监听 | 后续文档变化被合成为回放，不接管写入 |
| 通用动画输入 | 复制本次生成的暂存路径，让工具修改副本，保持真实目标文件可见 |
| Python 生成器 | 选择符合约定的生成脚本，具体要求见动画输入文档 |

暂存文件的路径含有会话编号。它只在对应输入会话运行时有效，不要复用旧的 `.swarm-...` 路径。结束时运行 **结束通用动画输入**。

## 4. 控制与恢复

- 暂停或继续：点击状态栏，或运行相应动画输入命令。
- 停止：运行 **停止动画输入（保留已输入内容）**，已提交部分保持原样。
- 备份：运行 **查看输入前备份**，打开只读原文。
- 撤销：正常成功完成的普通会话可用 `Ctrl+Z` 撤销整轮输入。
- 保存：检查结果后按需保存；扩展不主动调用保存。

## 5. 没看到动画

先确认当前是否走动画输入通道，以及工具是否真正被 Agent 调用。保持目标文件可见、VS Code 在前台，关闭自动换行并展开折叠。运行 **Code Swarm: 查看覆盖状态** 检查定位情况；更多说明见 [常见问题](FAQ.md)。
