最终磁盘与编辑器均为 1,656 行（含末尾空行），62,479 字节；缓冲区保持干净，原脚本字节未变。独立磁盘接收发现 947 次内容变化、0 次读取错误；渲染端接收 641 批尚未同步到编辑器的片段。271 次前台采样中有 263 次观察到可见绘制，实际绘制包括输入、描摹、绘框、复制、擦除和卡片六类动作，卡片布局记录五个出发方向。该比例是本机采样结果，不是帧率或逐行完整播放率保证。

## 复现

```powershell
npm ci
npm run check
npm test
npm run test:ui
$env:VSCODE_EXECUTABLE_PATH = 'C:\Program Files\Microsoft VS Code\Code.exe'
npm run test:extension
npm run test:webview
npm run package
```

`test:ui` 需要安装 Edge，或设 `PLAYWRIGHT_CHANNEL=chrome` 使用 Chrome。`test:extension` 和 `test:webview` 未设置本机路径时由官方测试库下载 VS Code，首次执行需要网络。`test:webview` 仅对临时测试实例开启动态本地调试端口，测试结束退出实例。

## 3 分钟手动演示

1. 安装 VSIX，打开命令面板运行“播放完整演示”。观察 32 个鼠标、逐字生成、任务面板；三幕自动衔接。
2. 在 MOVE 片段观察选区、悬浮代码片段和落点辅助线。试暂停、拖进度、重播和速度切换。
3. 打开 `examples/live-demo.ts` 的副本，运行“监听当前代码文件”，手动修改或让 AI 修改；舞台应生成新回放，来源显示未知。
4. 导入 `examples/proposal.json`。差异预览打开后检查原文保持不变，再应用，按 `Ctrl+Z` 检查一次撤销。
5. 再导入补丁，先手动编辑源文件，再尝试应用；旧补丁应失效而不是覆盖你的编辑。
6. 点击“清空 / 断开”，确认舞台回到起始状态；重新编辑源文件不再产生回放。

## 明确未覆盖

没有真实模型账户调用、真实 Codex/Claude 任务事件适配器、远程 SSH/WSL 环境、所有文件编码、所有操作系统、真实多文件原子提交、崩溃恢复、完整语义着色或 AST 移动识别测试。工作区信任拒绝逻辑已实现，但未在单独的不受信任窗口中自动测试。原型不应被理解为文件系统事务管理器。
